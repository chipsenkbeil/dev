dev help
  Show the commands, the details of one command or a help page

usage
  dev help [flags] [target...]

flags
  -a, --all             List the hidden commands and their layers
  --topics              List the help pages with their summaries
  -k, --topic <string>  Print one help page
  --no-pager            Print without a pager
  --check-topics        Check the help pages against the real commands and flags

arguments
  [target...]  A command, a subcommand or a help page (list)

Global flags:
  -v                      print each command before it runs, and debug log lines
  -vv                     also log every spawn with its folder, exit code and time
  -vvv                    also trace every native dev call, and run a .sh command under bash -x (that script only, not the scripts or tools it starts)
  -vvvv                   also trace calls between dev's Luau modules
  --remote                run this command on a remote runner, see `dev help remote`
  --local                 run this command here, whatever the default is (refused for a ci command under DEV_AGENT)
  --detach                with --remote, start the job and return
  --priority              with --remote, start the job ahead of normal ci jobs
  --job-timeout DURATION  with --remote, give the ci run a time limit
  -C DIR                  run as if dev started in DIR
  --version               print dev's version and exit
  -V                      the same as --version
  --agent NAME            export DEV_AGENT=NAME to the command
exit 0
