dev fetch
  Download the crates and advisory database an offline lint and test need

the built-in runs (rust project)
  env CARGO_NET_OFFLINE=false cargo fetch --locked

Global flags:
  -v          print each command before it runs
  -vv         also trace every line of dev and of each bash script
  --remote    run this command on a remote runner, see `dev help remote`
  --local     run this command here, whatever the default is (refused for a ci verb under DEV_AGENT)
  --detach    with --remote, start the job and return
  -C DIR      run as if dev started in DIR
exit 0
