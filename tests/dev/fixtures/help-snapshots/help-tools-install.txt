dev tools install
  Install the manifest's tools, only the package rows with --system or only the script and cargo rows with --user

flags
  --dry-run
  --force
  --group
  --system
  --user

the built-in runs (rust project)
  dev tools install [--system or --user] [--group NAME] [--dry-run] [--force] [tool...]

Global flags:
  -v          print each command before it runs
  -vv         also trace every line of dev and of each bash script
  --remote    run this command on a remote runner, see `dev help remote`
  --local     run this command here, whatever the default is
  --detach    with --remote, start the job and return
exit 0
